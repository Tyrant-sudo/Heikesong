# Vbot 大头 EDU 设备基线

## 确认结论

本项目从 `0.3.0` 起将目标真机固定为维他动力 Vbot 超能机器狗“大头 EDU 版”，设备配置文件为 `config/device/vbot_edu.yaml`，设备测试环境标识为 `HIL-VBOT-EDU`。

型号已经由项目方确认；序列号、硬件修订、固件、系统镜像、SDK、ROS 发行版和具体接口仍必须从到货设备及厂商开发包读取，未填写前不能进入运动测试。

## 尚待设备确认

- 序列号、硬件修订、固件与系统镜像版本。
- 厂商 SDK 仓库、接入指南、许可证与版本兼容矩阵。
- 是否采用 ROS 2、具体 ROS 发行版、RMW 实现及工作空间构建方式。
- node、topic、service、action、消息类型、QoS 和坐标系名称。
- RGB/深度/点云原始数据是否开放，以及分辨率、频率和时间戳来源。
- 速度控制、姿态动作、停止、控制权申请与反馈接口。
- 拍照接口、文件路径、图像时间戳和权限模型。
- 网络断开、进程退出、低电量和故障时的厂商安全状态。
- USB-C、电源和总线端口的实际规格、针脚、功率和可用权限。

公开页面未给出以上接口细节，项目不得猜测 topic 名称或直接套用其他品牌 SDK。

## 项目影响

- 原 `Blocked-by-SDK` 状态更新为 `Ready-for-EDU-HIL`，表示型号具备开发版定位，但仍需完成开发包和实机枚举。
- 任何环绕、跟随或模仿动作前，必须先通过身份版本、接口清单以及停止/失联测试。
- V1 视觉算法可优先复用设备相机流；若原始流未开放，则保留外接相机适配路径。
- ROS 2 仅在厂商资料或实机枚举确认后启用；核心领域接口继续保持 ROS 2 无关。
