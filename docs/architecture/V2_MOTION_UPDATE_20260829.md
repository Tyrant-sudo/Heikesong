# V2 运动功能更新（2026-08-29）

## 持续监听

进入瑜伽模式后，所有已注册动作口令均不再要求重复唤醒。身体动作运行期间继续处理离线语音，普通任务最多缓存 4 条并在当前动作安全完成后依次执行。“结束啦”优先于普通缓存任务。

## 俯卧撑

V2 使用 `/userdata/vbot/.local/share/heikesong/actions/PUSHUP_WITHOUT_LATE_HIGHS.json`。身体轨迹删除原厂第 178 至 273 帧，头部轨迹按时间比例删除第 72 至 109 帧，并保留原厂回正尾段。

## 结束击掌

瑜伽模式内识别到“结束啦”后，执行 `/app/config/dags/actions/HIGH_FIVE_R.json`。如果其他任务正在运行，则等待当前任务安全完成后击掌；击掌完成后退出瑜伽模式。

## 坐下倒数

视觉检测到长时间静止时只执行 `SIT_WITHHEAD.json`，不播放倒数。

只有语音“开始倒数”“倒计时”或“十秒倒计时”执行完整流程：先坐下，保持坐姿播放 10 秒倒数，然后恢复 `FIXED_STAND`。

## 语音灵敏度

“俯卧撑”“做俯卧撑”和短口令“俯卧”使用独立的高增益、低阈值关键词配置。调整只作用于俯卧撑，不降低其他口令阈值。

## 模式反馈

进入瑜伽模式后先恢复站立，再执行并等待开心动作完成。即使身体动作被安全上下文拒绝，仍播放“瑜伽开始了”并执行眨眼和闪屏反馈。

## 人员环绕

“绕圈”调用 `/heikesong/person_orbit/start_auto`，根据目标人的面部朝向选择环绕方向：人朝画面左侧时向左环绕（`direction=1`），人朝画面右侧时向右环绕（`direction=-1`）。正面、背面或关键点不足导致方向不明确时拒绝启动，避免猜错方向。手动调试仍可调用 `/heikesong/person_orbit/start`，并用参数 `direction=-1/1` 指定右绕或左绕。

- 侧移速度：`0.30 m/s`
- 基础转向速度：`0.35 rad/s`
- 视觉修正范围：`-0.70` 至 `+0.70 rad/s`
- 环绕时间：`6.8 s`

环绕服务会验证瑜伽垫上的目标人物、激光雷达距离和运动侧障碍；失败时恢复空闲状态并返回原因。
