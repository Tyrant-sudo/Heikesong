# V1 初版测试列表

本列表是 V1 的执行入口。详细步骤位于 `tests/scenarios/v1/`，实际阈值统一来自 `config/test/v1.yaml`，不在用例中散落硬编码。

| 编号 | 功能 | 核心检查点 | 层级 | 优先级 | 当前可执行环境 |
|---|---|---|---|---|---|
| `TC-MAT-001` | 识别瑜伽垫 | 正常识别、中心与边界有效、不同角度/光照/部分遮挡 | L1/L2/L4 | 高 | OFFLINE-CV |
| `TC-MAT-002` | 垫子误识别与丢失 | 非垫子不触发；连续丢失后取消依赖行为 | L1/L2 | 高 | OFFLINE-CV / SIM-MOCK |
| `TC-BEH-001` | 瑜伽垫附近环绕 | 轨迹在批准区域内、完成一圈、可取消、不踩入禁区 | L2/L3/L4 | 高 | SIM-MOCK |
| `TC-PER-001` | 识别用户位置 | 有人/无人、相对垫子的区域和位置连续性 | L1/L2/L4 | 高 | OFFLINE-CV |
| `TC-POSE-001` | 识别下犬式 | 正例、相似姿势负例、持续时间、离开姿势复位 | L1/L2/L4 | 高 | OFFLINE-CV |
| `TC-ACT-001` | 模仿与拍照 | 一次姿态事件只触发一次模仿和一次拍照，二者共用关联 ID | L2/L3/L4 | 高 | SIM-MOCK |
| `TC-BEH-002` | 跟随用户方向 | 方向变化后更新、微小抖动不频繁转向、用户丢失后停止 | L1/L2/L4 | 高 | SIM-MOCK / OFFLINE-CV |
| `TC-TIM-001` | 计时 | 开始、暂停、恢复、停止、到时与时间误差 | L1/L2/L4 | 高 | SIM-MOCK |
| `TC-SAFE-001` | 安全抢占 | 环绕/跟随期间遇人、障碍、失联或急停立即取消运动 | L2/L3/L4 | 必须 | SIM-MOCK |
| `TC-E2E-001` | V1 完整闭环 | 垫子→环绕→定位→跟随→下犬式→模仿/拍照→计时完成 | L2/L4 | 高 | SIM-MOCK |

## 首轮数据组合

| 变量 | 最小组合 |
|---|---|
| 瑜伽垫 | 目标垫、相似颜色非垫物、部分遮挡、移出画面 |
| 光照 | 正常、偏暗、逆光；照度范围在执行记录中实测填写 |
| 视角 | 正面斜视、侧面斜视、允许范围边缘 |
| 用户 | 无人、单人；多人不属于 V1 验收，只记录现象 |
| 姿势 | 下犬式、平板式、站立、俯身、跪姿 |
| 移动 | 静止、缓慢换位、方向突变、离开画面 |
| 计时 | 正常完成、暂停恢复、提前停止 |

## 执行顺序

1. 先执行计时器和行为规则的 L1 测试。
2. 使用录像与 Mock Adapter 执行感知和模块契约的 L2 测试。
3. 厂商 SDK、动作限制和安全参数确认后，才执行 L3 真机测试。
4. 所有单项用例通过后，执行 `TC-E2E-001` 和现场安全回归。

阈值为 `null` 的项目不得判定为现场验收通过；必须先通过数据校准或厂商资料冻结阈值并记录配置版本。
