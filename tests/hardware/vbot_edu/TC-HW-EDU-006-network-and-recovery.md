# TC-HW-EDU-006 网络、心跳与恢复

- 关联需求：DEV-EDU-007、SAFE-002
- 测试层级：L3
- 优先级：必须
- 自动化状态：Partial
- 适用环境：HIL-VBOT-EDU

## 前置条件

- 网络拓扑、允许的传输方式、心跳和超时机制已有厂商说明。
- `TC-HW-EDU-004` 的本地停止路径已通过。

## 步骤与预期结果

1. 记录连接建立、鉴权和时间同步过程，不记录密钥。
2. 空闲状态断开网络：状态明确，重新连接后接口可重新发现。
3. 最低批准速度运动时断网：在批准时间内停止。
4. 恢复网络：旧运动命令不续跑，需重新获得控制权。
5. 退出控制节点或停止心跳：行为与厂商安全规范一致。
6. 注入延迟和短时抖动：超过阈值时降级或停止，不积压陈旧命令。

## 通过标准

- 断网、进程退出和心跳丢失均有可观察事件和停止确认。
- 重连不会重放旧命令，时间同步满足传感器融合要求。
