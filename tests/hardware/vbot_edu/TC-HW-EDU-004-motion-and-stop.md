# TC-HW-EDU-004 运动控制与安全停止

- 关联需求：DEV-EDU-005、SAFE-001、SAFE-002
- 测试层级：L3
- 优先级：必须
- 自动化状态：Manual / Partial
- 适用环境：HIL-VBOT-EDU

## 前置条件

- `001`、`002` 已通过；场地、速度、距离、动作范围和停止阈值已批准。
- 有物理隔离、支撑/牵引保护、操作员和独立安全观察员。

## 执行阶段

1. **架空/支撑**：申请控制权，发送零速，验证反馈和取消。
2. **落地原地**：执行厂商允许的站立/趴下或模仿动作，验证超时和取消。
3. **最低批准速度**：分别发送短时前进、后退和转向，再发送零速。
4. 在运动中测试软件停止、操作员急停、控制节点退出和连接中断。
5. 恢复连接：旧命令不得自动续跑，必须重新申请控制并明确启动。

## 通过标准

- 命令单位、范围、控制频率、控制权和反馈与厂商文档一致。
- 所有停止路径在批准时间内进入厂商安全状态。
- 停止失败、异常加速或控制权不明立即判为 Blocker 并终止真机测试。
