# TC-HW-EDU-001 设备身份与版本确认

- 关联需求：DEV-EDU-001
- 测试层级：L3
- 优先级：必须
- 自动化状态：Manual / Partial
- 适用环境：HIL-VBOT-EDU

## 前置条件

- 设备断开所有非标外设并处于安全静止状态。
- 已取得订单、铭牌、装箱单和厂商版本查询方法。

## 步骤与预期结果

1. 核对厂商、产品名和 EDU 标识：与设备基线一致。
2. 记录序列号和硬件修订：同一批次内唯一且可追溯。
3. 读取固件、系统镜像、SDK 和开发文档版本：字段非空且兼容关系有依据。
4. 记录电池、传感器、关节和通信模块清单：差异明确登记，不用公开参考值覆盖实测值。
5. 将实测值填入本批次设备配置副本：不把序列号或凭据提交 Git。

## 通过标准

- 明确确认设备为 Vbot 大头 EDU，而不是消费版或轮足版。
- 固件、SDK、文档和系统镜像形成一组可复现版本快照。
- 所有差异均有厂商确认或缺陷记录。
