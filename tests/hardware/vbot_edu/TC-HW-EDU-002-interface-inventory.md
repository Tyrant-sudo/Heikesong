2. 记录中间件、ROS 发行版和 RMW（若适用）：与厂商兼容矩阵一致。
3. 枚举 node、topic、service、action：保存名称、类型、方向和用途。
4. 对 V1 所需接口记录 QoS、单位、频率、超时和权限。
5. 枚举坐标系并检查树：无循环、孤立或重复父节点。
6. 在独立会话重复发现：关键接口清单稳定。

## 通过标准

- 五类开放接口中与 V1 相关的能力均有正式文档或可枚举接口。
- 未发现或无权限的接口明确标记 `Blocked` 或 `Not Supported`。
- 不用猜测名称，不复用其他品牌消息定义。
