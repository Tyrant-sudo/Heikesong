# TC-HW-EDU-005 相机拍照链路

- 关联需求：DEV-EDU-006、CAM-001、CAM-002
- 测试层级：L3
- 优先级：高
- 自动化状态：Partial
- 适用环境：HIL-VBOT-EDU

## 前置条件

- 已确认原生相机是否允许单帧抓取；真人拍摄已取得授权。
- 存储位置、文件权限、命名规则和删除周期已确定。

## 步骤与预期结果

1. 使用唯一关联 ID 请求单帧：返回一个照片引用和采集时间戳。
2. 重复同一关联 ID：不生成第二张照片。
3. 触发下犬式事件：姿态、模仿动作和照片关联 ID 一致。
4. 注入相机忙、空间不足或接口超时：不无限重试，不影响机器人安全结束动作。
5. 检查照片清晰度、用户入画和隐私清理：符合批准配置。

## 通过标准

- 正常、重复和失败路径均可追踪。
- 原始照片不进入 Git；到期后可按记录删除。
- 原生接口不支持时记录 `Not Supported`，转入外接相机适配评审。
