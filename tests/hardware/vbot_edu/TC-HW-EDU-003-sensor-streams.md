# TC-HW-EDU-003 感知传感器数据流

- 关联需求：DEV-EDU-004、MAT-001、PER-001、POSE-001
- 测试层级：L3
- 优先级：高
- 自动化状态：Partial
- 适用环境：HIL-VBOT-EDU

## 前置条件

- 接口清单已冻结；测试期间机器人静止并处于支撑保护中。
- 相机和雷达的厂商工作范围、频率和安全注意事项已确认。

## 检查矩阵

| 数据 | 检查项 | V1 用途 |
|---|---|---|
| RGB | 分辨率、格式、帧率、曝光、时间戳、丢帧 | 垫子/用户/姿态识别 |
| 深度 | 单位、无效值、范围、与 RGB 对齐、时间戳 | 相对位置和安全距离候选输入 |
| 雷达 | 线数、覆盖、点频、范围、时间戳、frame_id | 环绕和障碍候选输入 |
| TF/姿态 | 坐标方向、静止漂移、更新频率 | 规划与数据融合 |

## 通过标准

- 实测流与厂商文档一致，连续采集时长和允许丢帧率达到批次阈值。
- 时间戳单调，RGB/深度/雷达可转换到已记录的统一坐标系。
- 关闭或丢失数据流时，上层收到明确错误，不继续使用陈旧观测。
