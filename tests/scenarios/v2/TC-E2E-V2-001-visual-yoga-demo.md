# TC-E2E-V2-001 视觉瑜伽完整演示

## 前置条件

- 佳佳静止，急停未激活，周围无障碍物；
- `/perception/poses` 只有一个稳定人物目标；
- 首轮使用 `HEIKESONG_V2_ENABLE_MOTION=0`；
- 观察员可随时停止测试。

## 步骤

1. 未进入瑜伽模式时做下犬式、俯卧撑并保持静止，确认无 V2 任务。
2. 说“佳佳”，再说“瑜伽模式”，确认眨眼和“瑜伽开始了”。
3. 保持粗略下犬式至少 1.2 秒，确认只产生一次下犬式任务。
4. 离开姿势后保持粗略俯卧撑至少 1.2 秒，确认只产生一次俯卧撑任务。
5. 保持姿势不动至少 5 秒，确认只产生一次坐下看人任务且不播放倒数。
6. 直接说“下犬式”“俯卧撑”“坐下看我”和“开始倒数”，确认模式内无需再次唤醒，且只有倒数口令播放十秒倒数。
7. 说“结束啦”，确认当前任务安全完成后执行右侧击掌并退出瑜伽模式。
8. 击掌任务完成后再次做姿势，确认已退出模式且不触发动作。

## 放行条件

- 无模式外动作、无重复动作、无视觉和语音双重执行；
- 人员丢失、多人切换或机器人非静止时不执行身体动作；
- 每个身体动作均有成功结果和安全恢复记录；
- 静止陪伴与语音倒数互不混淆，右侧击掌动作已由现场观察员单项确认。
