# TC-BEH-001 瑜伽垫附近安全环绕

- 关联需求：BEH-001、MAT-002、SAFE-001、SAFE-002
- 测试层级：L2 / L3 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：SIM-MOCK / HIL-VBOT-EDU / FIELD-YOGA

## 前置条件

- 垫子中心、边界和坐标系有效。
- 环绕距离、速度、完成容差和场地禁区已经批准并写入配置。
- 真机测试已准备物理急停与独立安全观察员。

## 步骤与预期结果

1. 发送稳定垫子观察：规划一条位于批准环带内的闭合轨迹。
2. 执行一圈：机器人不进入垫面禁区，不越出测试区，不产生无限绕行。
3. 小幅更新垫子位置：轨迹平滑更新，不发生突跳。
4. 注入垫子丢失、障碍、人员靠近和操作员停止：当前运动被取消。
5. 清除事件：系统等待明确恢复条件，不自动续跑旧轨迹。

## 通过标准

- 轨迹距离、完成时间和速度符合已批准阈值。
- 任一时刻只有一个移动行为持有控制权。
- 所有取消场景均记录请求、停止确认和最终状态时间戳。
