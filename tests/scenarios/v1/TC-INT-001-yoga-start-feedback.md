# TC-INT-001 瑜伽开始反馈

- 关联需求：DSP-001、VOI-001、INT-001
- 测试层级：L1 / L2 / L3 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：SIM-MOCK / HIL-VBOT-EDU / FIELD-YOGA

## 前置条件

- 屏幕、开心动作和 TTS Adapter 可记录调用顺序和关联 ID。
- 设备音量满足现场要求，屏幕不会显示闪烁频率过高的内容。

## 步骤与预期结果

1. 输入短口令“瑜伽功能”或“伽伽”：识别文本包含任一启动关键词，系统接受并生成一个 `correlation_id`。
2. 屏幕先眨眼再进行一次短闪反馈，不循环播放。
3. 执行一次“开心”动作；动作成功后播报“瑜伽开始了”。
4. 输入“开始瑜伽”或带首尾空格、句末标点的识别文本：包含“瑜伽”或“伽伽”即可匹配。
5. 输入“开始运动”等不含“瑜伽”的句子：不得触发任何反馈。
6. 开心动作被拒绝或停止：不得播报“瑜伽开始了”。
7. 在线 ASR 将“瑜伽”交给通用 Agent：判定路由失败；不得接受 Agent 自由生成的替代回答。

## 通过标准

- 正常顺序固定为眨眼闪屏、开心动作、TTS，三项使用同一 `correlation_id`。
- 单次关键词事件只触发一轮反馈；失败时不输出错误的成功播报。
- 真机上能目视确认屏幕效果并听清“瑜伽开始了”。
- `/speech/command_word` 或等效本地事件必须可追踪；仅由通用 Agent 理解语义不算通过。
