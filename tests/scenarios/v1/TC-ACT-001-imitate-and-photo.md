# TC-ACT-001 下犬式模仿与拍照

- 关联需求：ACT-001、CAM-001、CAM-002
- 测试层级：L2 / L3 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：SIM-MOCK / HIL-SDK / FIELD-YOGA

## 前置条件

- 输入为已经确认的下犬式事件，而不是原始模型分数。
- Mock 或真实 Robot Adapter、Photo Capture 可记录调用和关联 ID。
- 真人拍照已获得明确授权。

## 步骤与预期结果

1. 发送一次姿态确认事件：请求一次模仿动作和一次拍照。
2. 重复发送同一关联 ID：不得产生第二次动作或照片。
3. 冷却期内发送新帧但同一姿势会话：不得重复触发。
4. 模仿失败：记录动作失败，拍照结果独立可追踪，系统不无限重试。
5. 拍照失败：记录错误，机器人仍可安全结束动作，不无限重拍。

## 通过标准

- 动作、照片和原始姿态事件使用同一关联 ID。
- 单个姿势会话的动作次数和拍照次数均为一。
- 照片清晰度/构图达到批准阈值，存储引用符合隐私策略。
