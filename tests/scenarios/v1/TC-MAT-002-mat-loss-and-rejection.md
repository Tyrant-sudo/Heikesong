# TC-MAT-002 垫子误识别与丢失处理

- 关联需求：MAT-001、MAT-003、SAFE-002
- 测试层级：L1 / L2
- 优先级：高
- 自动化状态：Planned
- 适用环境：OFFLINE-CV / SIM-MOCK

## 前置条件

- 行为层已收到一个稳定的瑜伽垫观察结果。
- Mock Robot Adapter 正在执行或准备执行环绕。

## 步骤与预期结果

1. 输入没有瑜伽垫的连续画面：不得启动环绕。
2. 输入相似颜色地毯：不得形成稳定垫子目标。
3. 环绕中短暂遮挡：按配置的容错窗口保持或减速，不跳到新目标。
4. 遮挡超过丢失阈值：取消环绕并发出 `mat_lost` 原因。
5. 垫子重新出现：必须重新达到稳定条件，不能自动续跑旧动作。

## 通过标准

- 无无效坐标进入路径规划。
- 丢失与恢复过程只有一次取消和一次新的确认事件。
- 未配置丢失阈值时不得进入真机环绕验收。
