# TC-POSE-001 下犬式识别

- 关联需求：POSE-001、POSE-002
- 测试层级：L1 / L2 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：OFFLINE-CV / FIELD-YOGA

## 前置条件

- 数据包含不同体型、服装和允许视角下的下犬式标注。
- 姿态置信度、保持时间和冷却时间已经写入版本化配置。

## 步骤与预期结果

1. 输入站立、平板式、俯身和跪姿：不触发下犬式确认事件。
2. 输入短暂经过下犬式的动作：保持时间不足时不触发。
3. 保持标准下犬式至批准时长：只发出一个确认事件和关联 ID。
4. 持续保持姿势：冷却期间不重复触发。
5. 离开姿势并达到复位条件，再次进入：允许生成新的关联 ID。

## 通过标准

- 按数据分组统计的精确率、召回率和触发延迟达到批准阈值。
- 每次姿势会话的触发、抑制和复位均有时间戳。
- 相似姿势不得引起机器人动作或拍照。
