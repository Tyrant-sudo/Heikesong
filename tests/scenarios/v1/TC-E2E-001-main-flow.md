# TC-E2E-001 完整互动主链

- 关联需求：BEH-001、BEH-002、BEH-003、BEH-007、SYS-001
- 测试层级：L2 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：SIM-MOCK / FIELD-YOGA

## 前置条件

- 行为状态机、目标选择和可取消动作执行器已启动。
- 真机测试已通过人工开机前检查，并有独立安全观察员。
- 测试区域内先无人，随后由一名授权测试人员进入。

## 步骤与预期结果

1. 区域内无人：机器狗进入闲逛或安全等待，不发生持续折返。
2. 一名人员进入：人员列表更新，系统选择唯一互动目标。
3. 目标保持静止：机器狗以批准速度靠近并停在批准距离之外。
4. 靠近完成：机器狗坐下并保持头部朝向目标。
5. 用户小范围移动：头部跟踪，不重复触发靠近动作。
6. 用户明显换位：系统等待稳定后重新靠近同一目标。
7. 用户离场并超过丢失超时：系统取消跟随并回到闲逛或安全等待。

## 通过标准

- 状态迁移顺序正确，任一时刻只有一个移动行为拥有控制权。
- 全流程不存在无限寻找、无限移动和重复触发。
- 连续完成计划要求的重复轮次。

## 安全与清理

- 任一步骤均可由 Safety Override 中断。
- 失败时先停止运动，再保存非隐私结果摘要。
