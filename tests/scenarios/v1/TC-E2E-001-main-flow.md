# TC-E2E-001 V1 完整互动主链

- 关联需求：MAT-001 至 MAT-003、PER-001、PER-002、POSE-001、POSE-002、BEH-001、BEH-002、ACT-001、CAM-001、CAM-002、TIM-001、TIM-002、SYS-001
- 测试层级：L2 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：SIM-MOCK / HIL-VBOT-EDU / FIELD-YOGA

## 前置条件

- 单项用例已经通过，所有现场阈值已冻结。
- 行为协调器保证环绕和跟随互斥，所有运动可被安全层取消。
- 真机现场有授权测试人员、物理隔离和独立安全观察员。

## 步骤与预期结果

1. 启动会话计时器：状态进入运行并记录开始事件。
2. 放置瑜伽垫：系统确认中心与边界。
3. 请求环绕：在批准环带完成一圈并结束环绕状态。
4. 用户进入垫边位置：输出稳定用户位置和相对区域。
5. 用户改变方向并缓慢换位：系统更新跟随方向，保持批准距离。
6. 用户停止并保持下犬式：仅生成一个姿态确认事件。
7. 系统触发一次模仿和一次拍照：三者关联 ID 相同，冷却期不重复。
8. 暂停并恢复计时：暂停时间不计入；到时后状态为完成。
9. 用户和垫子离场：依赖行为取消，系统不继续移动。

## 通过标准

- 状态迁移、事件数量和顺序正确，同一时刻只有一个运动行为。
- 全链不存在陈旧坐标、无限寻找、无限移动、重复动作或重复拍照。
- 使用冻结配置连续完成计划要求的 10 轮。
- 任一步骤均可由 `TC-SAFE-001` 的 Safety Override 中断。
