# TC-MAT-001 瑜伽垫识别与定位

- 关联需求：MAT-001、MAT-002
- 测试层级：L1 / L2 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：OFFLINE-CV / FIELD-YOGA

## 前置条件

- 测试数据包含经人工标注的瑜伽垫中心和边界。
- 模型与 `config/test/v1.yaml` 的阈值版本已记录。

## 子场景

| 子场景 | 输入 | 预期结果 |
|---|---|---|
| A | 完整可见的目标瑜伽垫 | 输出 `detected=true`，中心和边界有效 |
| B | 不同允许视角和距离 | 检测指标达到已冻结阈值 |
| C | 偏暗和逆光 | 结果达到对应数据分组阈值，不静默输出无效坐标 |
| D | 部分遮挡 | 在标注允许范围内识别；超出范围时明确报告丢失 |
| E | 相似颜色地毯或地面区域 | 不产生持续的瑜伽垫确认事件 |

## 通过标准

- 检出、误检、中心误差和边界重叠指标达到配置中的批准阈值。
- `detected=false` 时不输出可用于运动规划的陈旧边界。
- 每条结果可追溯到输入帧、模型版本和时间戳。
