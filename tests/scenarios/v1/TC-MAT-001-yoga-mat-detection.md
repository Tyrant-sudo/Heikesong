# TC-MAT-001 瑜伽垫识别与定位

- 关联需求：MAT-001、MAT-002
- 测试层级：L1 / L2 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：OFFLINE-CV / FIELD-YOGA

## 前置条件

- 测试数据包含经人工标注的瑜伽垫中心和边界。
- 模型与 `config/test/v1.yaml` 的阈值版本已记录。

## 子场景

| 子场景 | 输入 | 预期结果 |
|---|---|---|
| A | 完整可见的目标瑜伽垫 | 输出 `detected=true`，中心和边界有效 |
| B | 不同允许视角和距离 | 检测指标达到已冻结阈值 |
| C | 偏暗和逆光 | 结果达到对应数据分组阈值，不静默输出无效坐标 |
| D | 部分遮挡 | 在标注允许范围内识别；超出范围时明确报告丢失 |
| E | 相似颜色地毯或地面区域 | 不产生持续的瑜伽垫确认事件 |

## 通过标准

- 检出、误检、中心误差和边界重叠指标达到配置中的批准阈值。
- `detected=false` 时不输出可用于运动规划的陈旧边界。
- 每条结果可追溯到输入帧、模型版本和时间戳。

## 识别失败兜底（最低改动）

在本地测试环境允许的情况下，若连续 20 帧 `detected=false`（或置信度长期低于阈值），立即转入微调采集，禁止继续发送环绕/跟随运动命令：

- 使用最近失败帧构建微调集：
  `python tools/yoga_mat_finetune_helper.py --source <failure_frames_dir> --out tests/reports/mat_finetune_dataset --label yoga_mat`
- 用标注工具补齐每张失败样本的瑜伽垫框。
- 完成后再运行训练命令（或在外部训练环境执行），并将新 `model_path` 更新到 V1 感知配置，复跑 TC-MAT-001。
- 本阶段不改写真实机行为参数，仅用于恢复识别可靠性。
