# TC-SAFE-001 安全事件抢占环绕与跟随

- 关联需求：SAFE-001、SAFE-002、SYS-001、MAT-003
- 测试层级：L2 / L3 / L4
- 优先级：必须
- 自动化状态：Partial
- 适用环境：SIM-MOCK / HIL-SDK / FIELD-YOGA

## 前置条件

- 环绕或跟随正在执行，动作支持取消。
- 阈值来自厂商资料和批准配置；真机有操作员与独立安全观察员。

## 安全事件矩阵

| 子场景 | 注入事件 | 预期结果 |
|---|---|---|
| A | 人进入批准停止距离 | 取消移动并确认零速度/厂商安全状态 |
| B | 路径出现障碍物 | 停止；满足明确恢复条件后才可重规划 |
| C | 操作员急停 | 抢占所有普通行为且保持安全状态 |
| D | 垫子或用户丢失超过阈值 | 取消对应环绕或跟随，不使用陈旧坐标 |
| E | 运动动作超过批准超时 | 取消动作并报告超时 |
| F | 控制连接或心跳中断 | 停止移动，恢复连接后不自动续跑 |

## 通过标准

- 六个子场景都能分别抢占环绕与跟随。
- 安全状态不会被计时、感知或普通行为覆盖。
- 日志包含触发、取消请求、停止确认和最终状态的时间戳。
- 停止时间达到已批准阈值；阈值未配置时真机结果只能记为 Blocked。

## 终止条件

出现停止失败、异常加速、跌倒风险或状态无法确认时，立即终止真机测试并登记 Blocker 缺陷。
