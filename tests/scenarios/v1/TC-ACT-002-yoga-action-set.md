# TC-ACT-002 V1 瑜伽动作集

- 关联需求：ACT-002、BEH-003、SAFE-001、SAFE-002
- 测试层级：L2 / L3 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：SIM-MOCK / HIL-VBOT-EDU / FIELD-YOGA

## 前置条件

- 下犬式组合、俯卧撑和趴下注视均通过正式 Robot Adapter 调用。
- 真机动作已完成逐项预检，场地、观察员和停止方式满足运动门禁。
- 坐下/趴下看人使用厂商 `SIT_WITHHEAD` 身体、头部和表情组合，避免独立头部控制触发自动站立。

## 步骤与预期结果

1. 请求下犬式：执行一次可取消的组合动作，包含进入、保持和安全恢复阶段。
2. 请求俯卧撑：执行一次完整动作并恢复到厂商批准的稳定姿态。
3. 请求坐下/趴下看人：执行 `SIT_WITHHEAD`，观察身体降低、头部朝向和表情动作，并等待稳定恢复。
4. 验证动作期间不启动独立 `head.ANGLE_CONTROL` 跟踪，避免姿态被强制切回站立。
5. 在每种动作期间请求软件停止：取消动作，不继续执行后续阶段或成功反馈。
6. 对同一 `correlation_id` 重复请求：编排层不得重复触发动作。

## 通过标准

- 三种动作均只通过版本化、可取消的厂商接口执行。
- 动作顺序、完成状态、超时、取消原因和 `correlation_id` 可追踪。
- 下犬式候选动作必须经现场录像确认形态后才能冻结映射；资源存在或预检成功不等于动作验收通过。
- 任一异常均返回稳定站立或趴卧状态，不自动续跑旧动作。
