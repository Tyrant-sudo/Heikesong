# TC-BEH-002 跟随用户方向

- 关联需求：PER-002、BEH-002、SAFE-001、SAFE-002
- 测试层级：L1 / L2 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：SIM-MOCK / OFFLINE-CV / FIELD-YOGA

## 前置条件

- 用户位置与方向观察结果带置信度和时间戳。
- 方向稳定时间、死区、丢失超时、速度和距离均已配置。

## 步骤与预期结果

1. 用户保持方向：跟随目标稳定，不反复重规划。
2. 用户方向发生超过死区的变化并保持：更新跟随方向。
3. 输入死区以内的左右抖动：不触发频繁转向。
4. 用户短暂遮挡：按配置等待或减速，不切换未知目标。
5. 用户丢失超过超时：取消跟随并停止移动。
6. 注入障碍或人员过近：Safety Override 抢占跟随。

## 通过标准

- 方向误差、更新延迟、跟随距离和停止时间达到批准阈值。
- 用户丢失、多人不确定或低置信度时不继续盲目移动。
- 不存在跟随与环绕同时控制运动的情况。
