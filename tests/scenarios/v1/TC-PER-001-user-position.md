# TC-PER-001 用户位置识别

- 关联需求：PER-001、PER-002
- 测试层级：L1 / L2 / L4
- 优先级：高
- 自动化状态：Partial
- 适用环境：OFFLINE-CV / FIELD-YOGA

## 前置条件

- 单人测试数据具有人工标注位置；涉及真人的数据已授权并匿名化。
- 若输出相对垫子位置，垫子坐标必须有效。

## 子场景

| 子场景 | 输入 | 预期结果 |
|---|---|---|
| A | 无人 | `detected=false`，不输出陈旧位置 |
| B | 单人静止 | 位置误差达到配置阈值 |
| C | 用户在垫子前、后、左、右 | 相对区域分类正确 |
| D | 用户缓慢移动 | 位置轨迹连续，不发生无依据跳变 |
| E | 用户被短暂遮挡或离开画面 | 按丢失阈值退出跟踪并通知行为层 |

## 通过标准

- 检出率、误检率、位置误差和丢失延迟达到已冻结阈值。
- 用户丢失后，跟随模块收到可取消信号。
- V1 多人输入不得随意切换目标；记录为不支持状态并停止相关移动。
