# TC-TIM-001 课程计时

- 关联需求：TIM-001、TIM-002
- 测试层级：L1 / L2 / L4
- 优先级：高
- 自动化状态：Automated / Manual
- 适用环境：SIM-MOCK / FIELD-YOGA

## 前置条件

- 使用单调时钟；自动化测试可注入 Fake Clock。
- 现场计时误差阈值已经写入配置。

## 步骤与预期结果

1. 启动正计时：经过时间单调增加。
2. 启动倒计时：剩余时间不小于零，到时进入 `finished`。
3. 暂停并等待：暂停期间经过时间不增加。
4. 恢复：从暂停值继续，不重复计算暂停时长。
5. 停止：最终值冻结，再次读取保持一致。
6. 输入零或负时长：拒绝启动并返回明确错误。

## 通过标准

- 自动化 Fake Clock 测试无累计误差。
- 现场运行的计时误差达到配置阈值。
- 开始、暂停、恢复、停止和到时各产生一次可追踪状态变化。
