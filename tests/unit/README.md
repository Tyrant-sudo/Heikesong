# 单元测试

此目录用于无硬件、无网络、可快速重复的测试。

当前及计划模块：

- `test_timer.py`：开始、暂停、恢复和到时逻辑。
- `test_yoga_interactions.py`：V1 动作路由、固定口令和反馈顺序。
- `perception/`：瑜伽垫、用户位置/方向、下犬式输出的规则和边界。
- `behavior/`：环绕、方向跟随、冷却、状态迁移和超时。
- `safety/`：规则优先级、停止条件和故障降级。
- `core/`：事件、世界状态和时间戳处理。

每个测试应在本地可独立运行，不访问真实摄像头和机器狗。

运行：`python tools/run_unit_tests.py`。
