# Vbot yoga audio assets

- `vbot_voice_reference_raw.wav`: raw six-channel microphone-array capture of the built-in `self_introduction` voice.
- `vbot_voice_reference.wav`: cleaned 16 kHz mono reference used for voice conversion.
- `yoga_start_vbot_voice.wav`: saved 16 kHz, 16-bit mono announcement for "瑜伽开始了", matching the robot's verified PCM playback path.
- `vbot_builtin_ai_direct_raw.wav`: raw six-channel capture of the prompted built-in AI response.
- `jiajia_wake_ack_builtin.wav`: short built-in wake acknowledgement used with the custom "Jiajia" keyword.
- `yoga_start_builtin_ai.wav`: preferred 16 kHz, 16-bit mono sample cut from the built-in AI's direct playback channel; only trimming, fades, and gain were applied.

The older `yoga_start_vbot_voice.wav` announcement was generated by converting a local Mandarin TTS source toward the captured Vbot reference voice. Prefer `yoga_start_builtin_ai.wav` for runtime playback because it preserves the built-in AI's natural voice. Playback uses the robot's `/speech_phone_to_dog` PCM stream because the firmware's custom-text `/set_speak` request was accepted but produced no audible output during V1 HIL testing.
